# AgentCF 与本地 Qwen：第一阶段

当前仅使用作者 CDs-100-user-dense，目标是先把真实数据、文字记忆更新和本地模型接通。Coat、KuaiRand 和人工场景不参与本次执行。

第一阶段已完成；实际结果、发现的接口故障和人工查看的记忆案例见 [阶段一结果](AgentCF阶段一结果_2026-10-15.md)。理论边界见 [偏差方法卡](AgentCF偏差方法卡_2026-10-15.md)。

## 为什么改这些代码

| 文件 | 改动与原因 |
|---|---|
| `diagnostics/agentcf_smoke.py` | 通过已有模型工厂调用 Qwen，记录实际模型配置和额度；冻结组只排序，不再生成随后丢弃的反思；网络失败停止，不能伪装成质量为零 |
| `datasets/author.py` | 保留作者 10 候选组装方式；增加只读数据概况，区分训练事件、历史前缀和训练未见物品 |
| `evaluation/author.py` | 集中计算单一已知目标的 NDCG@5、Hit@1/5 和热门曝光描述；不使用恒定的 Hit@10 |
| `recommenders/agentcf.py` | 补齐无效排序记录路径缺少的协议常量导入，避免模型漏排时触发程序错误 |
| `recommenders/replay.py` | 修正源事件再执行时也使用配置指定的模型，不再固定 DeepSeek |
| `runtime/models.py` | 不再把所有角色强制为中文，遵循当前任务的语言，保留作者英文记忆提示约束 |
| `deployment/qwen3/serve.sh` | 将自己的推理环境加入程序搜索路径，使编译能找到已安装的 ninja；不改系统 PATH 或权限 |
| `runtime/client.py` | 修正非空文本正则：原 `\S` 在实际结构化解码中只允许单字符；改为允许完整句子且必须含非空白字符的表达式 |

## 数据规则

作者提供 100 名用户、500 条训练目标事件，每人 5 条。前缀与目标合并去重后，每人涉及 6 个已观察物品。验证每人 1 个已知目标。`.random` 每人有 100 个候选编号，**没有评分，也不代表真实曝光**。

作者 `recall_budget=10, has_gt=True, fix_pos=-1`：去掉候选池里的目标，取前 9 个陪选，再加目标并打乱。默认沿用这一设置，不把 100 个池条目误当成 100 个排序候选。

热门度仅用 500 条训练目标事件计数，前缀不反复累加。按物品频次分组，同频物品不拆开，训练未见单列。热门占比与候选构成只作描述，不是因果去偏指标。

本实现用串行用户轮次、Python 随机打乱和 JSON 唯一编号，保留用户/物品文字记忆协同机制；与作者批处理及原模型存在差异，不声称数值复现。

## 怎样运行

服务器自己的环境：

```bash
export RSI_GPU_UUID=当前确认空闲的一张卡的UUID
bash /data/cjh/rsi/deployment/qwen3/start.sh
cd /data/cjh/rsi/project
/data/cjh/rsi/envs/research/bin/python -m rsi_researcher author-check \
  --config configs/qwen_agentcf_author.json --output runs/qwen-author-check
```

默认最多 120 次请求、750000 个估算额度 token、3600 秒；所有重试计入额度。默认 2 人、每人 5 事件。若中断，在同一份代码和配置下使用 `--resume` 恢复已提交事件；不会重复已经保存的排序。

`report.md` 是阅读入口；`input.json` 保存实际输入和提示词；`data_profile.json` 保存统计口径；`original_update/train-*.json` 保存前后记忆；`calls.jsonl` 保存真实请求、响应和消耗。测试替身不是实际推理记录。

## 第一阶段之后

检查通过后，固定开发用户，再检验未知反馈解释和热门兜底两种机制。优先复用已有 `uncertain_feedback`，若要单独归因则拆开它同时修改的多个假设。PAAC 的有依据记忆补充暂作后续假说，不复制热门专辑属性到冷门专辑。测试反馈不用于选改法或修改研究经验。

本阶段不实现训练事件并行调度，不预设提速倍数，也不把少量用户的指标变化写成研究收益。
