# Autonomous Bias Discovery — 机制与 Explorer Review（2026-10-23）

## 科学主张的精确边界

本项目当前已经让 Qwen3-8B 在不知道测试任务的机制类型、触发条件、目标标签和效应参数的情况下，提出并验证了**两类隐藏机制、共四个独立生成实例**：设备配置 × 用户群体的条件性交互，以及历史曝光反馈导致的状态依赖排序偏移。这里的“未知”指对受测 Agent 隐藏、需要其通过实验重发现。是否构成此前文献从未描述的新现实 Bias，须在真实推荐环境中继续检验，不能拿模拟器的标签代替审稿论证。

偏差参考：在模拟器中同一用户的固定物品相关性、相同候选集及随机数不应因无关设备条件、展示配置或额外曝光历史而无理由改变。实验观测目标是 **Top-3 中某一物品标签的占比**，不是 NDCG、不是第 3 名的曝光概率。

## 隐藏任务、研究轨迹与真实效应

### A: 设备 × 用户群体

隐藏条件：`device=1` 的影响只发生在 `segment_1`；`segment_0` 是范围反证对照。固定相同用户、6 个候选、随机条件，分别执行 `device=0` 和 `device=1` 排名。

| 盲测 | Qwen 初始方向/范围 | 干预检验、证据修订 | 独立确认效应（tag1 exposure@3） | 95% CI |
|---|---|---|---:|---|
| A / task-03 | 初始把 `segment_0` 和 increase 作为猜测 | `segment_0` 无效、`segment_1` 开发效应 −0.55729；修订范围和方向 | −0.46094 | [−0.51086, −0.41101] |
| B / task-01 | 初始对 history 检验零效应，随后选择 device；最初猜错群体和方向 | `segment_0` 无效、`segment_1` 开发效应 −0.49479；修订为 `segment_1/decrease` | −0.49740 | [−0.54747, −0.44732] |

两次独立确认均额外运行 `segment_0` 负对照，效应 0。Qwen 的最终实验结构正确：设备条件在特定用户群体中使 tag1 排名曝光比例系统性下降。模拟器的隐藏参数分别对应“相对提高 tag0”或“相对压低 tag1”，在二标签排名里其可观测结果等价，不能声称通过排名确定了唯一的绝对得分方向。

### B: 历史曝光事件 → 内部状态 → 后续排序

环境真实重放前两次曝光事件，由此前被推荐的目标标签数量更新用户记忆状态，然后在完全相同候选、用户偏好和噪声下执行后续排名。比较 `history=0` 与 `history=2`，只在 `segment_1` 有注入效应。

| 盲测 | Agent 的研究过程 | 独立确认效应 | 95% CI |
|---|---|---:|---|
| A / task-02 | 首轮 device 检验均为零；第二轮 history 检验，`segment_0`=0、`segment_1` 开发 tag1 效应 −0.16319；根据证据修订范围和方向 | tag1 −0.15625 | [−0.19213, −0.12037] |
| B / task-02 | 首轮 history，`segment_0`=0、`segment_1` 开发 tag0 效应 +0.16667；独立复验 | tag0 +0.13802 | [+0.10398, +0.17206] |

两个模型输出描述的是同一类可辨识排名关系（tag0 上升与 tag1 下降相对应），而不是两个全新概念。独立确认各包含 384 个处于 `segment_1` 的用户配对差值；另一用户群体负对照效应为 0。

### C: 失败实例和负对照

- 两套单因素隐藏任务都由 `slot` 配置影响 tag0 的排序得分（隐藏方向负、参数幅度 0.36），在两个用户群体均出现显著受控干预效应。**Qwen 没有测试它。**
- A 的三个候选：device → history → context；B：history → device → context。各检验两个 segment，开发集六次配对实验都返回零效应，因而没有进行独立确认。
- 但仅看**公开观测**，遗漏的 `slot` 在 A 两群体 tag1 曝光差异是 +0.4433/+0.4851，在 B 是 +0.4301/+0.5196。这些大幅度异常已出现在给 Qwen 的分组均值中，但旧 Explorer 未把它们提炼为研究线索。
- 两套 Null 任务检验 device、history、context 的各群体配对效应都为 0，最终没有宣布机制；正确弃权 2/2。需要注意：one-shot 不执行实验，因此它在 Null 上“不报告 confirmed”本身不等于有证据的否证。

## 关于 Qwen 自然语言解释的审稿问题

结构化真值评价（factor、segment、target tag、相对方向）通过 **不等于** 自由文本的机制叙述全部正确。旧记录存在：“曝光@3”被误写成“第 3 位曝光”；“历史曝光事件数量”被误写成“参与度”以及未经验证的系统解释。必须在报告中区分：

1. 模型在实验之前提出的假设；
2. 环境实际执行的干预、随机化单位、估计量和区间；
3. 模型实验后修正的范围/方向；
4. 独立评价器确认的结构化主张；
5. 尚缺证据、需要人工科学 Review 的语言解释。

不把模拟器的确定性因果公式当成 Qwen 自己推断出来的完整作用路径。

## Explorer v3 具体修改

修改仅限 `rsi_researcher/research/discovery_lab.py`、`discovery_cycle.py`、`tests/test_discovery.py`，复用原有 Qwen/vLLM 客户端、Journal 和独立确认，没有添加科研树。

- 环境从匿名的 384 用户公开推荐执行中，按每个测量字段及两个用户群体构建八张**观测证据卡**。每张记录高/低水平的样本量、tag1 Top-3 占比、观测差和描述性 95% 区间。这些是相关性对比，绝不等同于 `do` 干预或隐藏生成机制真值。
- 新的 Qwen Explorer 先读证据卡与历史无效实验，说明优先探索某一变量的观测证据、竞争解释以及可以推翻它的干预。因素选择是模型决定，框架只约束每任务最多三个不同字段以及可执行工具参数。
- Hypothesis Researcher 再围绕该因素生成自由表述的科学假设，不能预先从“Popularity/Selection/Memory”等 Bias 答案中选择，且不得将位置 3 或历史参与度混同于实验指标。
- 原有成对重新排名、两个群体独立检验、零效应时排除候选、显著效应后证据修订、独立用户复测完全保留。新增的机器生成证据陈述严格引用实际字段、水平、群体、tag 与 Top-3 指标；模型解释继续标为需科学 Review。
- 已经过 7 项针对性测试，包括观测证据卡不泄露机制标签和受限的真实检验驱动修订。Qwen 正式 v3 的运行结果单独记录，不覆盖 v2。

**科学目标仍是自主发现此前未指定的偏差机制**：先由真实行为异常触发假设，再用受控干预判断它是否相对于相关性/效用参照存在不合理系统性偏移。当前半合成环境只验证发现能力，后续须拓展可生成的机制家族与真实推荐任务，避免工作退化为四字段选择题。

### 具体修复了什么

- v2 两个 slot 单因素任务都没有检验 slot。v3 的第一套新盲测 slot 单因素任务，Explorer 首轮就引用公开观测证据选择 slot；两个用户群体的开发配对效应分别为 -0.52604、-0.55208，独立确认为 -0.49219，95% CI [-0.52757, -0.45681]。
- 第二套新种子的单因素机制作用于 device，而非 slot，同样得到正确确认。因此目前**slot 的新盲测直接证据是 1/1**，不能说 v3 又在两套独立 slot 任务上重复成功。
- 新工作流不是读取真实答案重新命名：Explorer 只接触公开的八张观测差异卡；Hypothesis Researcher 提出有竞争解释的可证伪假设；环境真实执行两组配对重排序；发现异常后根据证据修订方向与范围；独立 evaluator 最终判定。
- 原始 Qwen 的自由文本仍需科研审查：模型可能说出与代码证据不匹配的作用路径。数据契约新加 evidence_based_effect_statement，按实际实验字段和 exposure@3 写出可验证效应，同时将解释标记为待审查。
- 单一固定 4 字段的半合成环境尚不是开放变量空间。下一阶段重点应放在从真实推荐历史和商品语义中自动提出新候选属性，而不只是提高本 Benchmark 的 3/3 得分。
