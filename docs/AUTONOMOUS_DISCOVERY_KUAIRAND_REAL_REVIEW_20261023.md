# Autonomous Bias Discovery — 真实数据与 Debias 价值审查
日期：2026-10-23；代码目录：`/data/cjh/rsi/project/`

## 1. 研究目标和结论层级

需要发现的是“在推荐数据里尚未显式提供、可用观察和实验发现、相对于可信效用参照不合理、且可以通过干预改善的系统性机制”，**不是**仅把已有统计差异起一个新 Bias 名称。

建议使用连续状态：`observed_anomaly` → `replicated_regularity` → `mechanism_hypothesis` → `falsifiable_mechanism_supported` → `actionable_debias_candidate` → `independently_utility_validated_bias`。真正进入独立 Debias RSI 的条件至少包括：明确的影响条件与参考目标、受支持干预、独立效应估计、跨群体效用保护与对照；“是否文献上真的新颖”还要单独做先例检索和机制比较。

模拟器里的 `device=0/1` 是人为构造的、与固有用户兴趣无关的客户端上下文设置，不是现实日志里的手机设备型号或硬件参数。它的模拟检验价值是验证 Qwen 能否捕获并反证本不应该影响同一用户/候选相关性的外部因素。此前发现的类别分别是单因素无关设置作用、上下文 × 群体交互与历史曝光反馈，**不是已在真实生产系统验证的新 Device Bias**。

## 2. 大型数据集选型：KuaiRand-27K

正式的大规模研究对象确定为 **KuaiRand-27K**（官方 https://github.com/chongminggao/KuaiRand）：

- 完整版：27,285 用户、32,038,725 视频、322,278,385 次交互、15 类推荐策略、12 类反馈信号、时间戳和特征。
- 随机插入曝光：约 1,186,059 次随机曝光，项目说明随机替换比例约 0.37%，随机参考覆盖的候选池仅约 7,583 个视频。
- **优先使用完整 27K** 研究真实序列中兴趣变化、跨事件状态、交互作用和反馈路径；只在随机支持集内评价相对无偏的条件反馈，跨候选池的效果必须标为不能识别。
- 服务器目前已经拥有 KuaiRand-Pure（同 27K 用户、同 118.6 万随机曝光、但常规推荐序列仅保留候选池内记录），没有证据表明已经获得 KuaiRand-27K 完整压缩包；本轮真实数据计算在 Pure 上进行，不会冒充 322M 的全量实验。
- 不能仅凭随机组 CTR 高、常规组份额低判断算法偏差；视频池、流量来源、位置、播放环境、时段、个体偏好不同都可能解释差异。没有完整日志时不可声称已证明跨事件传播的因果机制。

## 3. 实际执行的 KuaiRand-Pure 真实数据探索

**数据与执行**：`rsi_researcher/research/kuairand_discovery.py`，tab=1（限定同场景），`is_rand` 严格区分真实随机插入曝光与常规推荐；视频 `tag`、时长、用户活跃度构成数据切片，不需要预定义四种 Bias 标签。

原始文件扫描：随机曝光 1,186,059，标准同期 295,497。排除不在 tab=1、时段或预定用户拆分之外的交互后，发展集随机 318,279、标准 96,756；留出集随机 154,135、标准 20,947。

训练/探索数据：哈希分组的 80% 用户、2022-04-22 至 04-30；独立确认：**不同的 20% 用户**、2022-05-01 至 05-08。确认证据不会传给 Qwen，模型只看探索期筛选结果。不同时间窗口仍可能有分布漂移，不能视为随机同分布复验。

Explorer 首先构造候选 **(用户活跃度 × 视频标签组合)、(用户活跃度 × 时长桶)、全体用户的视频标签/时长**。记录常规曝光份额、随机曝光份额、随机曝光 click CTR、其余同群体内容 CTR，以及按随机点击贡献得到的“反馈表现参照份额”。观察意义：支持探索曝光分配是否与随机参考反应不匹配；**不等于完整最优推荐策略**。

研究卡筛查 199 条可估计子群，发展集 8 条符合“高随机反馈 CTR + 常规曝光份额落后”预设筛查条件，6 条在独立用户/日期描述性重复出现。它们高度重叠于编码视频标签 `39,43`、`39,68` 和活跃度子群，不能独立地算成六种 Bias。官方标签仅为数字编码，不可臆断标签内容语义。

## 4. Qwen 实际提出的两个概念及科研 Review

Qwen3-8B 通过项目内已有 `ResearchAgent` / vLLM 成功发出 2 次结构化科研请求，输入**只有开发集观测卡**，不含留出结果。模型选择：

### 候选 C04：middle_active × 视频标签组合 39,68

- 发展随机曝光 CTR 0.247059；其他内容 0.187272，相差 +5.9787 个百分点。
- 发展常规曝光份额 2.2319%，随机参考点击贡献份额 5.7201%，相差 3.4883 个百分点。
- 留出用户聚类 CTR 差 +3.8144 个百分点，描述性 95% 区间 **[-0.092, +7.721] 个百分点**，包含零；确认样本的标准曝光计数不满足预设支持条件。
- 结论：**未确认描述性候选**；不得晋级机制或 Debias Task。

### 候选 C05：high_active × 视频标签组合 39,68

- 发展随机曝光 CTR 0.233535，其他内容 0.181005；差 +5.253 个百分点。
- 常规曝光份额 2.6367%，随机曝光中的“点击贡献份额”5.4781%，差 2.8414 个百分点。
- 留出随机曝光 CTR 0.227925，其他内容 0.194175。
- 留出按用户聚类点击优势 +3.352 个百分点，描述性 95% 区间 **[+0.993, +5.711] 个百分点**。同期常规曝光份额 2.1214%，独立随机参照的点击贡献份额 4.9761%。
- 假如额外向该类分配 **2 个百分点** 的曝光且用户/物品 CTR 保持不变，静态模型估计 CTR 改变 +0.06704 个百分点，用户聚类区间约 [+0.01986, +0.11422] 个百分点。**这是未经在线/真实排序执行验证的投影，不是 Debias 效果**。
- 结论：**已在不同用户与时段重复的描述性探索候选**。发生机制、其新颖性以及真实去偏效用尚未确认。

Qwen 的文字存在科学解释缺陷：它把随机插入样本占比描述成“系统刻意向该活跃度群体分配更多”，并未经证实建议“均衡所有群体曝光”。目前不能采纳这种方案。后续 Debias 应检验仅对相对高相关性且机会不足的切片做受约束微调，并在**真实执行可识别的固定推荐环境**评价效用，而非强制群体均分。模型输出不能自动晋级已验证 Bias。

额外的按用户聚类审计仅对 CTR 相关差异提供更合适的不确定性估计；没有消除自适应筛选、多重比较、环境混杂或候选池支持不足等问题。

## 5. 将 Discovery 显式衔接 Debias RSI 的验收门槛

每个候选在进入下游 Debias RSI 之前，至少具备：

1. **参考标准**：可信相关性/随机反馈，在明确支持集内，定义受损效用（例如点击、长观看、Top-K 相关性和受损用户群）。
2. **机制与作用边界**：具体变量、条件组合、干预反事实预测和竞争解释；在独立分层中成立，并有反证证据。
3. **可执行干预**：如修正上下文影响、去除错误反馈写入、改变排序/曝光份额；必须在真实推荐执行环境中可逆、可重放。
4. **效用及风险保护**：在独立随机参考或配对真实推荐实验下，目标损害下降，整体与最差子群效用无实质劣化；同时计入实验/模型成本。
5. **科研新颖性审核**：与经典 Popularity / Position / Exposure / Selection、相关反馈循环等机制比较，明确新增的条件、传播路径或失效边界。只有命名不同的不算新发现。

为使这套标准可执行，在半合成 `discovery_lab.py` 的干预实验中新增**与隐藏推荐偏差标签独立的用户真实兴趣参考**：对同一用户比较相关物品在 Top-3 中的占比，输出 treatment-minus-control、用户级配对 95% CI，以及是否存在可检测的效用损害。根据先前两套 v3 真实已保存任务，**事后补做**的效用审计中，六个注入机制实例均降低相关性参考下的 Top-3 命中比例；这些是事后验证，不得改写此前冻结的 Agent 发现证据，且属于刻意构造的半合成评分器。

## 6. 交付、复现和现实限制

- 代码：`rsi_researcher/research/kuairand_discovery.py`；扩展 `discovery_lab.py` 的 reference_utility；对应 `tests/test_discovery.py`。
- 运行：`runs/kuairand-real-discovery-20261023-v1/results.json`（真实日志扫描），`cluster_audit.json`（独立用户聚类 CTR 差），`qwen_concepts.json`（Qwen 原始研究提案与可审核轨迹），`model_calls/calls.jsonl`（真实 Qwen 请求及 Token）。
- Qwen 临时 vLLM 单 GPU 服务只为本轮实验启动，已发 SIGTERM 停止本任务创建的进程组。原有已有 Debias RSI、数据集文件和其他用户进程未修改。
- 真实数据结果并未进行新型隐藏机制恢复评价，因为真实日志没有完整 ground truth；只实现开放切片探索、Qwen 候选机制解释、独立描述性检验与可去偏性预评估。未运行真实推荐器反事实实验，**没有 confirmed causal real-world novel bias**。
- 下一阶段要先提供真实含时序的数据源（KuaiRand-27K）与实际可干预/可重放推荐模型，再让 Qwen 自主创建不局限于固定列的语义概念（用户兴趣转移、物品交互、延迟影响、跨用户传播），并在**真正的受控推荐执行**里通过/推翻机制。当前 27K 全量尚未下载或计算。
