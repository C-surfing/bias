## 核心判断

## GPT 研究假设与真正的自我反证

此前的数据发现，常规推荐事件中 **2,137,572 / 2,581,173 = 82.81%** 与上一事件共享完全相同的毫秒时间戳。若机械地将同一时间戳内连续的记录解释为“先前行为影响随后推荐”，可能会凭空制造算法反馈机制的叙述。

模型从同一个 DevelopmentTools 接口自主查询了曝光制度、同毫秒事件、tag 转移、用户内差异、批次大小和置乱负对照，具体 SQL 与输出见 `gpt-interactive/gpt_interactive_journal.json`。

开发集相同毫秒组中：
- 原始前驱反馈的条件点击率差：0.563582 - 0.265539 = **0.298043**。
- 在 `(uid,moment_ms)` 内用 `hash(vid,'shuffle20261024')` 置乱前驱的条件点击率差：0.559250 - 0.265714 = **0.293536**。
- 原始与置乱差约 **0.004507**（0.45 个百分点）。随机前驱近乎复制原始强相关，因此尚不能从该关联推断推荐器真的在同一毫秒内更新状态。
- 按用户等权统计原始前驱相关性：跨毫秒平均差约 0.0910，同毫秒约 0.1848。相关性并非算法实时更新的直接证据。

### 先冻结后打开诊断确认集

冻结预测文件：`gpt-interactive/frozen_diagnostic.json`，记录时间 `2026-10-24T08:35:38Z`，已声明确认集允许的唯一验证指标和 ±0.02 等效边界。

诊断确认结果：`gpt-interactive/diagnostic_confirmation.json`：
- 聚合原始与置乱相关性差 **0.0042295** (0.423 pp)。
- 280 名具备两种前驱条件的用户，按用户等权差值 95% 正态近似区间 **[0.00111, 0.00656]**（0.111–0.656 pp）。
- 这一区间落入预先指定的 ±0.02 边界。可称为支持“同批次共享因素足以产生大部分表面反馈关联”的诊断证据，不能称为证明内部推荐器不存在反馈或已经发现 Bias。

附加的同一事件行支持集敏感性检查（**事后提出，不是预注册确认**）：
`gpt-interactive/posthoc_same_row_support.json`。开发切片残差 0.00574，确认切片 0.00681，主要结论不变。此检查修正了原检验中两种前驱定义所用事件集合不完全一致的限制。

强烈提醒：完全相同的毫秒时间戳并不足以无歧义证明所有记录都是平台同一决策批次。可能包含日志时间精度/采集批处理效应。算法级 Bias 最终还需可执行推荐器和状态干预，而不能仅凭记录相关性确认。

## 瓶颈归因（现有证据下的最好判断）

**两部分问题都存在。当前最直接显露的是 Qwen 的研究行动质量不足，但不能量化 GPT 与 Qwen 的纯模型能力差异。**

1. **Harness 的已确认局限**：没有使用 `ORDER BY` 的原始 `SELECT` 受限于返回前 30 行，极易被同一用户同一曝光组主导；SQL 工具的字段与变量错误会消耗轮数；现有条件通过诸如两行对照数值审计后，仍没有系统地检验正确的因果可识别性。分层多用户初始观测能减少锚定，但单独使用没有使本次 Qwen 研究通过科学审核。
2. **Qwen 的可见局限**：面对准确的数据字典仍创造不存在的字段，把单标签/事件顺序相关性解释为机制；重复无效 SQL。直接提供关键负对照时能拒绝冒领因果结论，但忽视最有辨识力的 logged-vs-shuffled 比较，并再次生成使用不存在字段的查询。
3. **GPT 的真实进展与限制**：本会话能主动构造并执行负对照，自己反证原解释；其科研轨迹不等同于通过与 Qwen 完全一致的代码路径、模型工具配置和独立盲法测试。当前数据不能严谨宣布“GPT-6 解决了 Qwen 的模型瓶颈”。

## 下一步可决定性检验

真正识别模型与 Harness 的贡献应冻结下面的 2×2，并在全新用户和全新问题上运行至少 3 个独立重复：
- 两种模型：Qwen3-8B，GPT-6 系列 API（固定实际 model ID 与 reasoning effort）。
- 两种 Harness：原始开放接口，与仅改善多用户起始观测/SQL 失败反馈/研究记忆的开放接口。
- 两种模型**必须调用同一 ResearchAgent、同一 SQL 工具、同一研究预算与同一确认集盲审**。
- 主要结果：有效 SQL、可执行新变量、明确 falsifier 的概念、竞争解释的区分性实验、实质性修订、独立确认的有效发现数/请求或成本。
- 统计对照：先对相同研究案例做配对差异，不把单个失败或成功归因于某个模型。
- 只在模型程序化调用权限已经可验证时启动完整对照；避免用非等价的 Codex 代理或换成旧 GPT 型号冒充 GPT-6。

本轮所有实验均保存完整证据。没有更改原始日志，没有复用或打开正式科学 Holdout，也没有声称发现或 Debias 成功。
