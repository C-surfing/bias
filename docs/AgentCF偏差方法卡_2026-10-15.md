# AgentCF：供研究员使用的偏差方法卡

这是经源码与论文核对的研究输入，不是 Qwen 已经证明的结论。数据范围仅为作者 CDs-100-user-dense。

| 视角 | 当前能看什么 | 不能据此断言什么 |
|---|---|---|
| 选择 | 用户与物品的训练支持、抽样范围、训练目标与前缀的计数差别 | 已恢复全体用户的真实偏好 |
| 曝光 | 抽样未交互物品如何被解释成不喜欢，这种解释进入哪些记忆 | 候选文件代表真实曝光；已估计无偏点击率 |
| 从众 | 作者训练选择提示中的热门兜底、解释与记忆中的口碑措辞 | 真实用户因社会影响而从众 |
| 位置 | 固定同一记忆与候选，改变输入排列后的推荐变化 | 已测量真实界面上的点击位置偏差 |
| 热门结果 | 训练热门度分组的推荐曝光和已知目标命中；与候选构成共同报告 | 热门曝光少就是推荐更好；未见物品一定是相关长尾 |

综述的四类数据偏差是选择、曝光、从众、位置，热门偏差另行讨论。依据：[综述 §3.1、§4.6](https://arxiv.org/html/2010.03240v2)。

## 两个优先假说

**H1：未知反馈的解释可能污染用户记忆或正物品描述。** 当前执行只写正物品，不能假定负物品的生成描述已经落入共享记忆。先人工比较真实行为、反思提示和提交内容，再做仅改变未知反馈解释的对照。若针对性改法没有稳定减少这种误写或没有改善后续排序，缩小或撤回假说，不强行归因为曝光偏差。

**H2：训练选择阶段的明示热门兜底可能影响后续记忆与排序。** 该规则在 `system_prompt_template`，不是 basic 评测模板。改变它需要重新训练，不能加载旧训练记忆后声称移除了该机制。若改后没有预期变化，保留模型先验、训练支持差异等竞争解释。

现有 `uncertain_feedback` 同时改变未知反馈、属性虚构与泛化认可，适合作为综合修正，不足以单独识别每一项机制。依据：[作者提示与配置](https://github.com/leoleojie/AgentCF-WWW/blob/71ff3b5bce69432556884c49fe7f19528b6756ec/agentcf/props/AgentCF.yaml)。

## PAAC 的可借鉴范围

PAAC §3.1 利用共同交互者提供的监督来改善冷门物品的数值表示；§3.2 调整对比项，避免不同热门度表示被过度分离。它采用数值编码器与训练目标，不是文字记忆提示词算法。

本系统可以提出“冷门记忆是否缺少有依据的信息”这个问题，但同一个人喜欢两张专辑不等于它们具有相同乐器、节奏或情绪。缺少可核查证据时不得复制属性；不把给长尾加分的提示词直接叫 PAAC。依据：[PAAC §3.1–3.3](https://arxiv.org/html/2405.20718v1)。

## 给后续调研角色的任务

读取当前训练支持、记忆案例、排序指标和 Python 预计算的变化标签。区分事实、推断和未知。最多提出三个竞争假说；每个给出一个最小检查、一个具体改法和一个能推翻判断的结果。引用当前证据编号与论文位置。可以选择继续诊断、保持原版或承认证据不足，不预设一定存在偏差或某个动作必然成功。

历史只保留已试动作、结果和关键反例；具体用户/物品案例限定在当前任务。算术、门槛和评分由程序完成。失败结果如实存入条件假说卡，封存测试不用于下一轮选择。
